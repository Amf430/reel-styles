# reel-motion — موشن جرافيك كامل

مأخوذ من ريل إعلان كورس موشن بالذكاء الاصطناعي (`@r07qxo`، 35 ث، 720×1280): خلفية زرقاء بأشعة ضوء، نص Readex-like يطلع بالبلور، كروت زجاج، تحذير أحمر، تبويبات، زر Follow، شريط سعر. الأصل After Effects (Lens Blur + Directional Blur + Glow + كاميرا 3D)؛ هنا كله بالكود، وكل قطعة «beat» على تايملاين المحرّر.

**اقرأ `reel-engine` أول.**

## متى
- فيديو موشن كامل على تعليق صوتي (إعلان، شرح، عرض مشروع، كورس).
- مقطع موشن قصير بين لقطات تصوير (انترو/أوترو/فاصل).
- **مو** لطبقة فوق تصوير — للنص فوق المقدّم استخدم `reel-captions` / `reel-hook` / `reel-glass`.

## المخرج
خلفية كاملة ProRes 422HQ (`output: opaque`) — تنحط على التايملاين بدل اللقطة. البرفيو فيه صوت `video` المشروع.
- **المشروع بدون فيديو:** حط `"size": [1080, 1920]` و`start/end` في الجوب (البرفيو بدون صوت).
- **مع تعليق صوتي:** حطه كـ `video` في project.json (أي ملف فيه ستريم فيديو؛ تسجيل صوت فقط حوّله: `ffmpeg -f lavfi -i color=black:s=1080x1920 -i vo.m4a -shortest vo.mp4`) ثم `transcribe.py` يعطيك توقيت كل كلمة.

## سير العمل
1. `transcribe.py vo.mp4 --out reel_work/words.json` ← قسّم الكلام لجمل، كل جملة beat.
2. لكل beat: `in` = بداية أول كلمة، و`at` = توقيت كل كلمة **نسبةً لـ in** (`s − in`). الكرت/الشريط: نسبةً لـ `in + text_delay`.
3. `--stills` على لحظة من كل beat ← المحرّر ← الرندر.
4. **الرندر النهائي دايماً `--mblur 4`** (موشن بلور حقيقي من 4 فريمات فرعية) — بدونه الحركة تطلع جامدة.

## الحركة (وش يخليه حي)
- **كاميرا لكل beat** (`cam`): كل لقطة تبدأ مقرّبة ومايلة (`scale` 1.2، `rot` −6°) وتستقر ببطء (`dur` 3 ث، ease-out)، وبعدها تبعد شوي شوي (`drift`) مع تمايل خفيف (`sway`). مفعّلة افتراضياً للنص والصور والشعار؛ مطفية للكرت والشريط والـ Follow (ثابتة في المرجع). `cam: false` أو `cam: {scale: 1.4, rot: -10, dur: 3.5}` لكل beat، و`params.cam` للكل.
- **كاميرا الفريم كامل** (`camera`): keyframes `[{at, scale, rot, x, y, dur}]` بأوقات مطلقة، + `float` (اهتزاز يد خفيف، 1). الخلفية تتحرك أقل (عمق).
- **الكلمة**: تنزلق من جهة القراءة (`text.slide` 70u) + بلور + تكبير خفيف ← تستقر (ease-out quint)، والسطر المتوسط يعيد توسيط نفسه مع كل كلمة جديدة (`recenter`).
- **الانتقالات**: `up`/`down` (سكرول يطلع الإطار كامل)، `below`/`above` (يدخل من تحت/فوق)، `through` (يطير من/إلى العدسة)، `whip-left/right`، `zoom` (من 0.2)، كلها بموشن بلور باتجاه الحركة.

## الحقول
عام (`params`):
```json
{
  "font": "Readex Pro", "google_fonts": ["Readex Pro"], "logo_src": null,
  "text": { "size": 100, "weight": 400, "line": 1.4, "stagger": 0.16, "word_dur": 0.5, "blur": 14, "rise": 16, "dim": 0.4, "kashida": 0.15, "justify": true, "glow": 0 },
  "bg":   { "speed": 1, "rays": 4, "ray_strength": 0.75, "ray_len": 0.7, "shade": 0.75 },
  "tones": [ { "at": 24.55, "tone": "alert", "dur": 0.4 }, { "at": 27.0, "tone": "base" } ],
  "beats": [ ... ]
}
```
- `tones`: الخلفية تتحول لـ `alert` (أحمر) أو `purple` (قلق/توتر) وترجع `base` — بأوقات مطلقة.
- **الكشيدة (توقيع الستايل):** كل سطر قصير يتمطّ لعرض أطول سطر في نفس النص، والمطّ يصير عند علامات `ـ`. حط `ـ` **وحدة** بين حرفين يتصلون في الكلمة اللي تبيها تتمطّ (لكـن، قـدامـك، مـقعـد) — الطول يتحسب تلقائياً. `justify: false` يوقفها.
- `logo_src`: شعار العميل (PNG شفاف). بدونه نجمة مرسومة بالكود.

كل beat: `type`, `in`, `out`, `x`, `y` (مركز، نسب 0..1)، `enter`, `exit`, `in_dur`, `out_dur`, `moves`, `z`, `label`.
- **الحركات** (`enter`/`exit`): `blur` · `rise` · `fade` · `zoom` · `pop` · `up` · `down` · `whip-left` · `whip-right` · `none` (والكرت عنده `shatter`). `up/down/whip` فيها موشن بلور باتجاه الحركة.
- `moves: [{ "at": 1.0, "y": 0.17, "dur": 0.8 }]` — ينزلق لمكان جديد (at نسبةً لـ in). مثل «لكن لا تخاف» يطلع فوق لما يظهر الأوبجكت.

| type | حقول | الشكل |
|---|---|---|
| `text` | `text` (`\n` سطر جديد، `*كلمة*` لون hl، `ـــ` كشيدة)، `at`، `size`, `w` (عرض، 0.86)، `align`, `anchor` (`center` يتوسّط مع كل سطر جديد / `top`)، `style` (يغيّر أي قيمة من `text`) | كلمة كلمة: بلور + رمادي ← أبيض. الخروج الافتراضي `up` |
| `card` | `text`, `at`, `text_delay` (0.45)، `w` (0.62)، `h`, `pad`, `radius`, `sparkles` (true)، `warn` (⚠️×3)، `tone: "alert"` (زجاج أحمر)، `deco_size` | كرت زجاج يبلّر الخلفية، يدخل `zoom`، يطلع `shatter` (whip + شرر) |
| `tabs` | `items` (تبويبات)، `y`, `gap`, `stagger`, `size`, `tab_h`, `zoom: [1, 2.3]`, `cam_delay`, `cam_dur`, `tilt`, `focus_x/y`, `lift` | كروت مجلدات سودا تطلع من تحت وحدة وحدة، والكاميرا تدخل وتميل |
| `band` | `text`, `at`, `text_delay`, `y`, `h` (0.32)، `logo` (true)، `logo_size`, `spin` | خطين مضيئين ينفتحون من النص، زجاج بينهم، الشعار تحت يدور |
| `follow` | `label` ("Follow")، `tap` (وقت الضغطة، مطلق)، `w`, `h`, `logo_size` | شعار + زر زجاج يلمع بكسلات ثم الكلمة، مؤشر أزرق يدخل ويضغط |
| `image` | `src`, `w`, `h` (نسب؛ افتراضي الشاشة كاملة)، `fit` (`cover`/`contain`)، `radius`, `push` (رقم = Ken Burns بطيء 1.06، أو `[1.35, 1]` + `push_dur` = يدخل مقرّب ويستقر)، `float` (يطفو — لأوبجكت PNG)، `panel: {w,h,y,radius}` (كرت زجاج وراه — مثل الشخص قدام الكرت) | صورة/رسمة/أوبجكت 3D مرندر |
| `clip` | مثل `image` + `from` (بداية المقطع بالثواني)، `speed` | فيديو (يتحول لفريمات تلقائياً ويتكيّش في `~/.reel-styles/clips`) |
| `logo` | `size`, `spin` | الشعار لحاله |

## الثيمات
كل ثيم فيه `base` و`alert` و`purple`.
- `blue` (الافتراضي، مثل المرجع): كحلي `#030c3c` → `#0a1f80`، أشعة `#1f45ff`، تحذير `#6e0f1a`.
- `seen`: عنابي سين `#46081f` مع ذهبي `#e2c3a4`.
- `mono`: أسود/رمادي.
كل الألوان في الثيم: `base/alert {deep, mid, ray, shade}`, `text`, `hl`, `glass`, `glass_alert`, `stroke`, `spark`, `tab`, `tab_text`, `band`, `line`, `pill`, `ray`, `logo`.

## حدود
- **الأوبجكتات 3D** (كرة تتحول عين ثم أيقونة) ما تنبني هنا — رندرها من Blender/Spline كـ PNG/فيديو وحطها `image`/`clip` (`float: true`).
- **الرسومات** (الشخص بالشماغ، الغرفة) أصول من برا (رسم/AI) — تنحط `image` مع `whip`.
- Readex Pro من Google Fonts (يحتاج نت وقت الرندر)؛ بدون نت يرجع Tajawal.
- الكشيدة تنرسم كخط بنفس سماكة وارتفاع تطويل الخط (مقاسة من الخط نفسه) — تشتغل مع أي خط عربي.
- **قبل الرندر:** تأكد إن كل سطر يطلع سطر واحد (`size`/`w`) — لو التف، قلل `size`.
