# reel-engine — المحرّك المشترك

كل ستايل `reel-*` هو مجلد فيه `scene.html` (المشهد) و`presets.json` (القيم الافتراضية والثيمات والسلايدرات) و`SKILL.md` (متى يُستخدم وقائمة المعتمد/المرفوض). المحرّك واحد للكل.

```bash
REEL="$(cd ~/.claude/skills/reel-engine && pwd -P)/../.."   # جذر الريبو (المهارات روابط رمزية له)
```

## المتطلبات (تحقق مرة لكل جهاز)
- `python3` + `playwright` (`pip3 install playwright`)، وChromium من Playwright. المحرّك يلقى أي نسخة Chromium موجودة حتى لو رقمها مختلف عن الباكج (أو حدد `REEL_CHROMIUM=/path`).
- `ffmpeg` فيه `prores_ks` (نسخة Homebrew فيها).
- `bash "$REEL/install.sh"` يربط المهارات في `~/.claude/skills/` ويفحص كل هذا.

## الجوب (job.json) — شغل واحد = ملف واحد
احفظه جنب فيديو المستخدم في مجلد `reel_work/` (لا تعدّل ولا تحذف ملفات المستخدم). التعليقات `//` تحت للشرح فقط — JSON الحقيقي بدونها.
```json
{
  "style": "reel-glass",
  "video": "../clip.mp4",          // يحدد المقاس والـ fps والصوت تلقائياً (طولي أو عرضي)
  "start": 12.0, "end": 18.5,       // ثواني على تايملاين الفيديو — الطبقة تبدأ عند start
  "theme": "frost",                 // من presets.json للستايل
  "name": "cards_intro",            // اختياري: اسم الملف الناتج
  "params": { ... }                 // فوق الافتراضيات؛ كل ستايل يشرح حقوله في SKILL.md حقه
}
```
- كل المقاسات داخل المشاهد بوحدة `u` = 1px على ضلع قصير 1080، والمواقع نسب من الإطار (0..1) ⇒ نفس الجوب يطلع صح طولي وعرضي.
- 4K يترندر بـ device scale 2 تلقائياً.

## الأوامر
```bash
python3 "$REEL/engine/render.py"  job.json --stills 13.2,15.8   # صور سريعة للفحص (+ مركّبة على الفيديو)
python3 "$REEL/engine/player.py"  job.json [--t 13]             # برفيو مباشر في المتصفح
python3 "$REEL/engine/render.py"  job.json [--workers 6] [--mblur 4]   # الرندر الكامل
python3 "$REEL/engine/key.py"     clip.mp4 --out reel_work/keyed/subject.mov --start 12 --end 18.5
python3 "$REEL/engine/shadow.py"  subject.mov --out shadow.mov   # (render.py يسويه تلقائياً للستايلات اللي تحتاجه)
python3 "$REEL/engine/composite.py" --out p.mp4 --size 1080,1920 --dur 6 a.mov b.mov@0.1,0,0.8,1
```

### البرفيو المباشر (player.py)
نفس الفريمات بالضبط مثل الرندر، فوق فيديو المستخدم وبنفس نسبة أبعاده. افتحه في Browser pane (`preview_start` بالرابط) أو المتصفح.
- `space` تشغيل/إيقاف · `←/→` ±1ث (`shift` ±5) · `,` `.` فريم · `l` تكرار · `b` قبل/بعد · `w` wipe (حرّك الماوس) · `h` إخفاء الواجهة · `?t=12` يبدأ من ثانية.
- السلايدرات على اليسار من `tune` في presets.json. زر **save to job** يكتب القيم في job.json — اقرأ الملف بعدها وكمّل منه.

## المخرجات (out/<style>/)
| الملف | وش هو | وين يروح |
|---|---|---|
| `<name>_<0m12s00>.mov` | الطبقة: ProRes 4444 شفاف (glass/neon) أو ProRes 422HQ (خلفيات) | البريمير، عند الوقت المكتوب في الاسم |
| `…_subject.mov` | المقدّم مفصول ومحطوط بمكانه (full frame شفاف) | فوق الخلفية |
| `…_shadow.mov` | ظل المقدّم (backdrop فقط؛ في studio3d الظل داخل الخلفية) | بين الخلفية والمقدّم |
| `…_preview.mp4` | كل شي مركّب مع الصوت | للمراجعة والإرسال فقط |
| `….meta.json` | التوقيت والمقاس ومكان المقدّم | مرجع |

ترتيب الطبقات في البريمير (من تحت): الخلفية → الظل → المقدّم → neon/glass.

## فصل المقدّم (key.py)
- يشتغل فقط إذا الخلفية تنفصل: كروما خضراء/زرقاء، أو استوديو بخلفية سادة وكاميرا ثابتة (`--mode plate --plate empty.png` = فريم للمكان فاضي).
- **تصوير في موقع حقيقي = لا تفصل.** استخدم الستايلات اللي فوق الفيديو (glass, neon) بس.
- المفتاح difference key (`G − max(R,B)`): الثوب الأبيض والرمادي والبشرة تبقى صلبة. لو بقى أخضر: `--similarity 0.1`. لو الأطراف تنأكل: `--similarity -0.05`. حوامل/إضاءات على الأطراف: `--matte x,y,w,h`.
- دايماً افتح `_qc.jpg` (الماجنتا = اللي انشال) قبل ما تكمل، وشغّله على نفس `--start/--end` حق الجوب.

## سير العمل الإلزامي
1. افهم الطلب → اختر الستايل → اكتب job.json.
2. `--stills` على 2–3 لحظات مهمة → شوف الصور بنفسك → صحح.
3. اعرض على المستخدم البرفيو (player) أو الصور. المستخدم يحب تجربة 5–10 ثواني قبل التعميم، ومقارنة خيارات جنب بعض.
4. الرندر الكامل → ارسل `_preview.mp4` واذكر أسماء الطبقات ووقت كل وحدة.
5. ملاحظة اعتمدها أو رفضها المستخدم؟ اكتبها في قسم «معتمد/مرفوض» في SKILL.md حق الستايل (شوف «تحديث الستايلات»).

## تحديث الستايلات (الريبو `Amf430/reel-styles`)
الستايلات تتطور مع كل شغل. أي تعديل على ستايل أو المحرّك:
1. الريبو هو مصدر المهارات (المجلدات في `~/.claude/skills/reel-*` روابط له): `cd "$REEL"`.
2. فرع جديد من `dev`: `git switch dev && git pull && git switch -c style/<name>-<change>`.
3. عدّل `scene.html` / `presets.json` / `SKILL.md` (المعتمد/المرفوض + سطر في «سجل التغييرات»).
4. اختبر بـ `--stills` على فيديو حقيقي.
5. commit باسم المستخدم فقط (بدون أي ذكر لـ AI)، `git push -u origin HEAD`، و`gh pr create --base dev`.
6. لا push مباشر على `dev` أو `main` أبداً. الترقية dev→main فقط لما يقول المستخدم «ارفع».
- قيمة جديدة بس (ثيم/لون معتمد)؟ أضفها كـ theme في presets.json بدل ما تغيّر الافتراضي.

## مشاكل معروفة
- `scene failed to load` → شوف رسائل الكونسول في الخطأ؛ جرّب `player.py` وافتح الكونسول.
- خطوط Google: `"params": {"google_fonts": ["Cairo"]}` ثم `"font": "Cairo"` في السطر (تحتاج نت وقت الرندر). Tajawal مضمّن.
- الكشيدة (ـ) في Tajawal قصيرة؛ للتمطيط الواضح كرر 2–3 مرات.
