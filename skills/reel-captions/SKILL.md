# reel-captions — كابشن كلمة كلمة

ترند 2026: 70–85٪ يتفرجون بدون صوت ⇒ الكابشن المتحرك أساسي. القوالب المكررة تنكشف بسرعة، فغيّر الثيم/الألوان حسب الحساب.

**اقرأ `reel-engine` أول.**

## الخطوات
1. **التوقيت:**
   - Whisper (الافتراضي، على الجهاز):
     `python3 "$REEL/engine/transcribe.py" ../clip.mp4 --out reel_work/words.json [--start --end] [--prompt "سين العقارية، حي النرجس"]`
     أول مرة يثبّت faster-whisper وينزل النموذج (~800MB) في `~/.reel-styles`. بعدها ثواني.
   - أو SRT مصحّح (CapCut): `transcribe.py --srt subs.srt --out reel_work/words.json`
2. **الإملاء:** اعرض الأسطر على المستخدم أو قارنها بالنص المكتوب. صحّح `"w"` فقط في words.json (لا تلمس `s/e/g`). أسماء الأماكن والأرقام أكثر شي يغلط.
3. جوب captions → `--stills` → المحرّر.

## الحقول (params)
```json
{ "words": "words.json", "keywords": ["إنجاز", "حلم"], "colors": { "خصم": "#3ddc5c", "مرفوض": "#ff3b3b" },
  "y": 0.72, "max_words": 3, "auto_numbers": true }
```
- `keywords`: كلمات تتلون بلون `hl` دايماً. `colors`: لون خاص لكلمة (ستايل MrBeast: أخضر للإيجابي، أحمر للسلبي). `auto_numbers`: الأرقام تتميز تلقائياً. أو حط الكلمة بين `*…*` في words.json.
- التجميع: `max_words`, `max_chars`, `pause_break` (وقفة تكسر الجملة)، ولا يدمج جملتين أبداً (حقل `g`).
- `in/out` اختياري (افتراضي: من أول كلمة لآخرها). `y` = مكان السطر (0.72 = تحت الوسط، بعيد عن أزرار المنصة). `strip_punct`.
- الثيم يحدد: `size, weight, text, active, hl, stroke_w, shadow, reveal (word|phrase), pop, box, dim, rise`.

## الثيمات
| الثيم | الشكل |
|---|---|
| `hormozi` | عريض، حد أسود، الكلمة الحالية صفراء، المهمة خضراء، تنط — 3 كلمات |
| `mrbeast` | أضخم وحد أعرض، كلمتين، ألوان حسب المعنى (`colors`) |
| `box` | الجملة كاملة، الكلمة الحالية بوكس أصفر |
| `karaoke` | الجملة كاملة باهتة، تنور كلمة كلمة |
| `clean` | ستايل Ali Abdaal: ناعم، بدون حد، ظهور هادي |
| `yellow` | Yellow font confessions: أصفر كبير على لقطة هادئة، جمل أطول |
| `seen` | هوية سين v6: أبيض Tajawal، الكلمة المهمة نيون `#ffe066` |

## نصائح
- لقطة فاتحة: `hormozi`/`mrbeast`/`box` (الحد يضمن القراءة). `clean`/`seen`/`yellow` تحتاج لقطة أغمق أو ظل أقوى.
- كلمة مميزة وحدة لكل جملة تقريباً — كثرة الألوان تضيّع.
- لما يطلع hook أو كروت بنفس الوقت، حرّك الكابشن (`y`) أو اقطعه في المحرّر.
