# reel-frames — خطوط وزوايا

إطار هندسي هادئ: خطوط رفيعة تطلع من الزوايا وتمتد برا الحدود، ونقاط ذهبية مضيئة على التقاطعات. المحتوى يتبدل داخله والإطار يتحرك لمقاسه الجديد.

**اقرأ `reel-engine` أول.**

## الحقول (params)
```json
{ "items": [
  { "type": "text", "phrases": ["هذه *الفكرة* ببساطة", { "text": "خطوة *صغيرة* كل يوم", "at": 2.2 }], "in": 1, "out": 5, "y": 0.15, "size": 55 },
  { "type": "text", "text": "ابدأ *اليوم* | بخطوة صغيرة", "in": 5, "out": 8, "y": 0.3, "size": 80 },
  { "type": "photo", "images": [{ "src": "a.jpg", "label": "المرحلة *الأولى*", "aspect": 0.8 }, { "src": "b.jpg", "label": "المرحلة الثانية", "aspect": 1.78, "at": 2.2 }], "in": 8, "out": 13, "x": 0.5, "y": 0.6, "w": 0.6 },
  { "type": "photo", "img": "before.jpg", "label": "قبل", "glow": true, "in": 13, "out": 16, "w": 0.5 }
] }
```
- `type: "text"`: `text` (`|` = سطر جديد) أو `phrases` (تتبدل؛ `at` بالثواني من بداية الـ item، أو كل `every` ث). `*كلمة*` بلون الثيم. `pad` (المسافة داخل الإطار).
- `type: "photo"`: `img`+`label` أو `images` (معرض يتبدل والإطار يتشكل لكل صورة). `w` عرض (نسبة)، `aspect` (عرض/ارتفاع). `glow: true` = إطار متوهج بدل الخطوط (قبل/بعد) والتسمية فوق بالنص.
- عام لكل item: `in`, `out`, `x`, `y` (مركز)، `size` (u)، `accent`, `ext` (طول الخطوط برا الإطار، em)، `line_opacity`, `look` (`lines`|`glow`)، `sfx`, `xf`.

## الثيمات
`gold` (الأصلي) · `cyan` · `red` · `white` · `seen`.

## الصوت
رسم الخطوط + تكة النقاط، وكل تبديل عبارة (swipe) أو صورة (shutter).
