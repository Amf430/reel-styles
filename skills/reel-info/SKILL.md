# reel-info — عناصر معلومات

بلوكات جاهزة للمعلومة: مين المتكلم، كم المساحة، وش المميزات، متى الموعد، وين تلقانا. تصميم نظيف (بطاقات بيضاء أو غامقة)، دخول محسوب، وصوت لكل عنصر من `reel-sfx`.

**اقرأ `reel-engine` أول.**

## الحقول (params)
```json
{ "items": [
  { "type": "lower", "text": "م. خالد العتيبي", "sub": "مدير المبيعات", "icon": "user", "in": 1.2, "out": 4.5, "x": 0.94, "y": 0.8 },
  { "type": "stats", "text": "المبيعات هذا الشهر", "value": "1,250", "delta": "+12%", "in": 5, "out": 9, "y": 0.3 }
], "out_dur": 0.35, "sfx": true }
```
لكل item: `type`, `in`, `out`, `x`, `y`, `size` (u، الافتراضي 70 — كل المقاسات تتبعه)، `align` (`right`/`center`/`left` — وين ينحط x)، `accent`, `color`, `font`, `sfx`, `sfx_gain`, `out_anim: "cut"`, `xf`. `*كلمة*` = مميزة.

| type | الحقول | الشكل |
|---|---|---|
| `title` | `text`, `sub` | خط جانبي يطلع + عنوان ينسحب + سطر فرعي |
| `bar` | `text`, `w` (نسبة العرض، 1)، `bg`, `text_color` | شريط عرضي ملون |
| `highlight` | `text` بـ `*كلمة*` | الكلمات تطلع ثم بوكس ملون ورا الكلمة |
| `lower` | `text` (الاسم)، `sub` (الصفة)، `icon` | تعريف أسفل الشاشة (ينحط من اليمين: `x` = الحافة اليمين) |
| `card` | `icon`, `text`, `sub`, `w` (em) | بطاقة بأيقونة وعنوان ونص |
| `stats` | `text` (عنوان)، `value`, `delta`, `bars` | رقم يعدّ + نسبة ▲/▼ + أعمدة |
| `number` | `value`, `unit`, `sub` | رقم ضخم يعدّ + وحدة + خط + وصف |
| `calendar` | `day`, `month`, `weekday`, `sub` | ورقة تقويم تنقلب |
| `list` | `items` (نص أو `{text, icon}`)، `numbered`, `stagger` | قائمة عمودية بعلامات ✓ أو أرقام |
| `row` | `items` (`{text, icon}`) | صف كبسولات |
| `grid` | `items` | شبكة عمودين |
| `pill` | `icon`, `text` | كبسولة بأيقونة تنفتح |
| `end` | `text`, `sub` (الحساب)، `logo` (صورة)، `buttons` (`[[icon, نص]]`) | شاشة ختامية تغمّق الفيديو |
| `callout` | `px,py` (النقطة)، `x,y` (مكان البطاقة)، `text`, `sub`, `icon` | نقطة تنبض + خط + بطاقة |
| `orbit` | `px,py` (المركز)، `items`, `radius` | بطاقات حوالين نقطة بخطوط |

الأرقام (`value`, `day`) تعدّ وتحافظ على شكلها: `1,250` و`٣٥٠` و`4.5`.
الأيقونات: `bed bath area pin tag check star phone building key car clock arrow sparkle home bulb book target warning x question lock user userplus heart bell bookmark share play calendar money trend cursor chart`.

## الثيمات
`light` (بطاقات بيضاء، أزرق — الافتراضي) · `dark` (بطاقات غامقة، أصفر) · `gold` · `red` · `green` · `seen` (عنابي + بيج).

## نصائح
- `lower` أول ما يظهر المتكلم، 3–4 ث. `end` في آخر 2–3 ث.
- `callout`: حط `px,py` على الشي نفسه بالمحرّر، والبطاقة في مكان فاضي.
- عنصرين بالكثير بنفس الوقت.
