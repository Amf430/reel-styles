# reel-hook — عنوان الافتتاح

ترند 2026: «oversized centered hooks in heavy sans-serifs» — أول 3 ثواني تقرر إذا المشاهد يكمل. سطر أو سطرين ضخمين بالنص، كلمة وحدة مميزة بلون.

**اقرأ `reel-engine` أول** (المشروع، المحرّر، التسليم).

## الحقول (params)
```json
{
  "lines": [ { "text": "شقة *180 م²*", "size": 150 }, { "text": "بـ *سعر* ما تتوقعه", "size": 110 } ],
  "sub": "حي النرجس — الرياض",
  "x": 0.5, "y": 0.42, "in": 0.1, "out": 3.0,
  "anim": "punch", "anim_dur": 0.5, "stagger": 0.12, "out_anim": "pop", "shake": 0
}
```
- `*...*` = الكلمة/العبارة المميزة (لون `hl`). كلمة وحدة لكل سطر كحد أقصى.
- `size` بوحدة u؛ السطر الأعرض من `max_width` يصغر تلقائياً. لكل سطر: `weight`, `font`, `box` (لون بوكس خاص).
- `anim`: `punch` (يكبر وينزل مع ارتداد — الافتراضي) · `slam` (يطيح من فوق ببلور + هزّة عند الهبوط) · `type` (كلمة كلمة) · `rise` · `stretch`.
- `out_anim`: `pop` · `slide` · `cut`. `shake` 0–1 هزّة مستمرة (للطاقة العالية بس).
- `sub`: سطر صغير تحت (موقع/سعر/اسم).

## الثيمات
`punch` (أبيض + أصفر + حد أسود — الأكثر انتشاراً) · `box` (بوكس أسود، الكلمة صفراء) · `white-box` (بوكس أبيض، الكلمة حمراء) · `red` (بوكس أحمر) · `clean` (بدون حد، ظل فقط) · `seen`.

## نصائح
- 3–6 كلمات للسطر الأول. الرقم أو الفايدة هي الكلمة المميزة.
- على لقطة فاتحة: `punch` أو `box` (الظل وحده ما يكفي، `clean`/`seen` تحتاج لقطة أغمق).
- خلّه يطلع في أول 0.1–0.3ث ويطلع قبل أول قطع رئيسي (المحرّر يوريك القطع).
