# reel-textfx — نصوص متحركة

مكتبة حركات نص قصيرة (عبارة أو كلمة) تنحط فوق التصوير في أي مكان. كل حركة دخولها مدروس ويطلع معها صوت متزامن (`<layer>_sfx.wav`). الكود كله مكتوب هنا؛ المراجع كانت معاينات شكلية فقط.

**اقرأ `reel-engine` أول.** الأصوات من `reel-sfx`.

## متى
- تأكيد كلمة أو عبارة قصيرة وقت الكلام (2–5 كلمات).
- عنوان قسم، اسم متحدث، رقم، سؤال، خبر.
- **مو** للعنوان الافتتاحي الضخم (`reel-hook`)، ولا للكابشن الكامل (`reel-captions`).

## الحقول (params)
```json
{ "items": [
  { "fx": "kashida", "text": "*الحكاية* بدأت", "in": 3.2, "out": 6.0, "x": 0.5, "y": 0.3, "size": 110 },
  { "fx": "news", "text": "خبر اليوم باختصار", "sub": "عاجل", "in": 7.0, "out": 10.0, "y": 0.82, "size": 90 }
], "out_dur": 0.35, "sfx": true, "sfx_gain": 0 }
```
لكل item: `fx`, `text` (`*كلمة*` = مميزة)، `in`, `out`, `x`, `y` (مركز النص كنسبة)، `size` (u)، واختياري: `color`, `accent`, `accent2`, `weight`, `font`, `speed` (>1 أسرع)، `stagger`, `out_anim: "cut"`, `sfx` (false أو id صوت بديل)، `sfx_gain`, `xf`.

## الحركات
| fx | وش يسوي | خيارات |
|---|---|---|
| `select` | تظليل يمشي على النص ثم ينشال (تحديد نص) | — |
| `type` | كتابة حرف حرف مع مؤشر يرمش | `per` (ث لكل حرف) |
| `pop` | الكلمات تطير من أماكن مختلفة وتنط مكانها | `stagger` |
| `rise` | الكلمات تصعد من بلور | `stagger` |
| `drop` | الكلمات تطيح من فوق وترتد | `stagger` |
| `kashida` | الكلمة المميزة (أو الأطول) تتمطط بكشيدة | `kashida` (عدد ـ) |
| `underline` | خط يترسم والنص يطلع من تحته | — |
| `box` | صندوق ملون يكشف النص (نص غامق) | `text_color` |
| `brackets` | زوايا تركيز تنفتح حوالين النص | — |
| `glitch` | قلتش RGB يتكرر | `every`, `accent2` |
| `news` | شريط خبر مع تاق (`sub` = نص التاق) | `sub` |
| `bubble` | فقاعة كلام بيضاء تنط | `text_color` |
| `glowchar` | الحروف تضوي حرف حرف | — |
| `swipe` | سحبة سريعة بموشن بلور وخط ضوء | — |
| `reveal` | شرارة ضوء تمشي وتكشف النص | — |
| `twotone` | سطرين بلونين `"سطر أول \| سطر ثاني"` والثاني بكشيدة | `kashida` |
| `stack` | كل كلمة سطر بكشيدة، ودائرة على الأولى | `kashida` |
| `name` | اسم عربي مضيء + اسم لاتيني (`sub`) يطلع حرف حرف + نقاط | `sub` |
| `spot` | ضوء كشاف يمشي ويكشف النص (`*30%*` بلون) | — |
| `frame` | إطار متوهج يترسم حوالين المتحدث + سطرين تحت | `w`, `h` (نسبة)، `sub` |

## الثيمات
`auto` (كل حركة بلونها الافتراضي) · `gold` · `pink` · `teal` · `yellow` · `red` · `seen`. أي item يقدر يغيّر `accent`.

## الصوت
كل حركة لها صوت (pop لكل كلمة، typing للكتابة، shine للإضاءة…) يطلع في `<name>_sfx.wav` بنفس بداية الطبقة. `"sfx": false` لـ item = بدون صوت، `"sfx": "ding"` = صوت بديل.

## نصائح
- حركة وحدة لكل عبارة، وما يزيد عن عبارتين على الشاشة بنفس الوقت.
- على لقطة فاتحة: `box`, `news`, `bubble` (خلفيتها تحميها). النيون والتوهج أحلى على لقطة غامقة.
- `kashida`/`twotone`/`stack` تحتاج كلمة فيها حرف يقبل التمطيط (ما تنفع على «دار» مثلاً)؛ علّم الكلمة بـ `*...*`.
- `frame`: حطه على المتحدث (x,y مركز الإطار) واضبطه في المحرّر.

## حدود
- الحركات على مستوى الحرف (`glowchar`) تلوّن بس بدون تحريك، حتى ما ينكسر وصل الحروف العربية.
- `type` يكتب النص كامل بدون تمييز `*...*`.
