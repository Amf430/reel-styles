# reel-neon — عنوان نيون

مأخوذ من ريلز «كل مدرسة ناجحة» (AE: Deep Glow، Radius قليل، Exposure ~0.3). يطلع أحلى على خلفية غامقة (studio3d/backdrop أو تصوير ليلي)؛ على مشهد فاتح التوهج يضعف — قل للمستخدم.

**اقرأ `reel-engine` أول.**

## الحقول (params)
```json
{
  "lines": [ { "text": "كل مدرسة", "size": 120, "weight": 800 }, { "text": "نـاجـحـة", "size": 150, "weight": 900 } ],
  "x": 0.5, "y": 0.18, "align": "center", "line_gap": 0.12, "max_width": 0.86,
  "in": 2.0, "out": 7.5, "anim": "rise", "anim_dur": 0.9, "out_dur": 0.4, "stagger": 0.18,
  "outline": false,
  "glow": { "intensity": 1, "spread": 1, "bloom": 0.55, "hum": 0.03 }
}
```
- `x,y` مركز الكتلة (أو حافتها مع `align: right|left`). `size` بوحدة u (px على 1080). السطر الأعرض من `max_width` يصغر تلقائياً.
- لكل سطر: `glow`, `core` (ألوان تتخطى الثيم)، `font` (مع `google_fonts`)، `in`.
- `anim`: `rise` (يطلع من تحت ببلور) · `flicker` (تشغيل نيون: تقطيع ثم ثبات — حتمي) · `write` (ينكشف بالاتجاه) · `glow` (التوهج يزيد تدريجياً).
- `outline: true` = شكل أنبوب نيون (حد بدون تعبئة).
- الكشيدة في Tajawal قصيرة: «نـاجـحـة» ⇒ للتمطيط الواضح «نــاجــحــة».

## نيون المتحدث (`items`)
بلوكات حوالين متكلم (تشتغل مع `lines` أو لحالها)، كل وحدة بـ `in/out`:
```json
"items": [
  { "type": "word", "text": "الفكرة البسيطة | تنتشر أسرع", "in": 1.0, "out": 4.0, "y": 0.2, "size": 80 },
  { "type": "pill", "text": "النقطة الأولى", "sub": "ابدأ بخطوة صغيرة", "in": 4.2, "out": 7, "y": 0.4 },
  { "type": "banner", "text": "بسيطة", "in": 7.2, "out": 9, "y": 0.8, "thick": 0.08 },
  { "type": "banner", "img": "guest.jpg", "label": "ضيف الحلقة", "in": 9, "out": 12, "y": 0.75, "thick": 0.06 },
  { "type": "number", "text": "?", "words": ["الوقت", { "text": "التركيز", "at": 1.6 }], "in": 12, "out": 15, "y": 0.32 },
  { "type": "side", "text": "بدل ما تنتظر | الفرصة المثالية | ابدأ من اليوم", "side": "right", "in": 15, "out": 18 },
  { "type": "flash", "in": 18, "out": 18.5 }
]
```
| type | الشكل | حقول |
|---|---|---|
| `word` | سطور بيضاء، خط نيون يمسح تحت كل سطر ويكشفه (`\|` يفصل السطور) | `text` |
| `pill` | عنوان + كبسولة نيون تحته | `text`, `sub` |
| `banner` | شريط نيون متموج عرض الشاشة، عليه كلمة غامقة؛ أو صورة ضيف بإطار نيون + تاق | `text`, `img`, `label`, `thick`, `img_x`, `img_w` |
| `number` | رمز/رقم عملاق مخطط بالنيون + صبغة خضرا على الشاشة + كلمات تتبدل تحته | `text`, `words` (`at` بالثواني من البداية)، `glyph`, `tint`, `wy` |
| `side` | دائرة نيون كبيرة على جنب الشاشة (نصها برا الإطار) فيها سطور + ومضة أول ما تدخل | `text`, `side`, `d`, `flash: false` |
| `flash` | ومضة لون النيون على الشاشة كاملة (فاصل/انتقال) | `strength`, `dur` |
- اللون من الثيم (`glow`) أو `glow` لكل item. الثيم `green` = ستايل نيون المتحدث الأخضر.
- `number` يطلع أقوى ورا المتكلم: استخدم `behind` على الجوب (شوف reel-behind).
- كل بلوك معه صوته في `<layer>_sfx.wav`.

## الثيمات
`green` (نيون المتحدث) · `amber` (برتقالي ذهبي — مثل الريلز الأصلي) · `seen` (`#ffe066` نفس v6) · `pink` · `ice` · `lime` · `white`.

## ملاحظة لسين
seen-motion (v6) **رفض** الفوشي/البرتقالي والوميض المتكرر لفيديوهات سين الإعلانية. لشغل سين الرسمي: ثيم `seen` و`anim: rise` أو `glow` — لا `flicker`. للسوشل ميديا الحرية أوسع.
