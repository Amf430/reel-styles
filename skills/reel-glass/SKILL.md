# reel-glass — كروت زجاجية

مأخوذ من تحليل ريلز «Glass Shape» (After Effects: Brightness −50 + Gaussian Blur + Stroke Soft Light 70%، حركة Position سريعة ثم بطيئة). هنا نفس الوصفة بالكود.

**اقرأ `reel-engine` أول** (الجوب، الأوامر، التسليم، تحديث الستايل).

## متى
- مميزات عقار (غرف، مساحة، موقع)، أرقام (+250,000 م²)، عناوين صغيرة، خطوات.
- أي تصوير — ما يحتاج فصل المقدّم.

## المخرج
ProRes 4444 شفاف: برا الكرت شفاف، وداخل الكرت **البلور محسوب من الفيديو نفسه** ⇒ حطه فوق نفس الكليب وعلى نفس الوقت بالضبط (اسم الملف فيه الوقت). لو تحرك الكليب في البريمير، أعد الرندر.

## الحقول (params)
```json
{
  "stack": { "x": 0.9, "y": 0.2, "gap": 22 },
  "cards": [
    { "kind": "stat", "value": "+180", "unit": "م²", "label": "مساحة الشقة", "icon": "area", "in": 24.4, "out": 30.6 },
    { "kind": "card", "text": "٣ غرف نوم", "sub": "ماستر بدورة مياه خاصة", "icon": "bed", "in": 24.7, "out": 30.6 },
    { "kind": "pill", "text": "جاهزة للسكن", "icon": "check", "in": 25.0, "out": 30.6 }
  ]
}
```
- **الافتراضي = عمود (stack):** الكروت اللي بدون `x/y` تتصف تحت بعض بنفس العرض (= الأعرض، أو `stack.width` نسبة)، على حافة واحدة (`stack.x`؛ في RTL الحافة اليمنى — غيّرها بـ `anchor: left|center|right`)، تبدأ من `stack.y`، ومسافات متساوية `gap` (u).
- كرت بـ `x,y` (الزاوية العلوية اليسرى، نسب) يطلع من العمود ويتحط حر. `w`/`h` نسب اختيارية.
- `kind`: `card` (عنوان + سطر فرعي) · `stat` (رقم يعدّ من صفر خلال `count_dur` ثانية، يحافظ على +/الفواصل/الأرقام العربية) · `pill` (كبسولة سطر واحد).
- `in/out` بالثواني على تايملاين الفيديو. `from`: bottom/top/left/right. لكل كرت: `in_dur`, `out_dur`, `dist`, `size`, `sub_size`, `radius`, `tint`, `align: "center"`.
- الأيقونات: bed, bath, area, pin, tag, check, star, phone, building, key, car, clock, arrow, sparkle, home, chart (`engine/web/icons.js` — أضف جديد هناك).
- عام: `glass.{blur, brightness, saturate, radius, corner ("squircle" افتراضي | "round"), stroke, stroke_opacity, highlight, shadow}`، و`round: true` للكرت = كبسولة دائرية (خارج القاعدة — استخدمه لحاله بس), `text.{size, weight, sub_size, icon_size}`, `motion.{in, out, dist, content_delay}`, `dir` (rtl).

## أشكال إضافية (ما تدخل العمود)
مكانها بالمركز `cx, cy` (نسب، الافتراضي وسط الإطار):
| kind | الشكل | حقول |
|---|---|---|
| `title` | كرت عنوان بالنص، سطرين بـ `\n` | `text`, `sub` |
| `arch` | قوس زجاج طالع من تحت الإطار (صورة دائرية فوق + نص تحت) | `w`, `h` (نسب)، `img`, `img_scale`, `sink`, `y` |
| `lens` | عدسة زجاج دائرية تكبّر اللي وراها | `d` (نسبة من الضلع القصير)، `zoom` (0.4) |
| `bubble` | فقاعة زجاج فيها صورة دائرية | `d`, `img` |
| `orbit` | دائرة زجاج بنص + حلقة عليها نقاط مرقمة (خطوات) | `d`, `steps`, `active` أو `step_times` (أوقات مطلقة)، `ring` |
| `icon` | أيقونة زجاجية كبيرة: الخط نفسه زجاج يبلّر اللي وراه، بحواف مضيئة، تنرسم ثم تطفو | `icon` (`bulb book clock target warning check x question chart lock` وأي أيقونة)، `s` (الحجم)، `stroke`, `accent`, `blur`, `draw` |

## صور داخل الكروت
أي `card`/`pill`/`stat`/`title`/`arch` يقبل `img` (مسار نسبي للجوب): `img_shape`: `circle` (افتراضي) · `square` · `wide`، و`img_size` (نسبة من حجم الخط). `layout`: `row` (الصورة جنب النص) · `col` (الصورة فوق) · `bottom` (النص فوق والصورة تحت).

## الصوت
كل كرت يطلع بصوته (swipe_ui، pop للكبسولة، count_up للأرقام، bubble للدوائر، shine للأيقونة) في `<layer>_sfx.wav`.

## الخامة: frost أو liquid
- `frost` (الافتراضي): زجاج مضبّب — البلور قوي، الخلفية تختفي.
- `liquid` — ستايل Apple Liquid Glass: بلور خفيف والخلفية واضحة، **انكسار** عند الحواف (الصورة تتكبر وتنحني مع خيط ألوان خفيف)، **لمعة** تلف حوالين الحافة ببطء، و**وضوح تلقائي**: لو اللي وراه مزدحم أو فاتح يزيد البلور ويغمّق لحاله (لكل فريم).
  `glass.liquid.{blur, edge, refract, chroma, spec, spin, rim, adapt}`. فعّلها بثيم `liquid`/`liquid-dark` أو `"glass": {"material": "liquid"}`.

## الثيمات
`frost` (أبيض فاتح — للمشاهد الفاتحة) · `smoke` (زجاج غامق — للمشاهد الغامقة/الليل، أقرب لريلز AE الأصلي) · `seen` (عنابي + بيج) · `warm` · `ice` · `liquid` (Liquid Glass فاتح) · `liquid-dark`.

## نصائح
- المشهد فاتح جداً؟ `smoke` أو `glass.brightness` 0.5–0.6 عشان النص الأبيض يقرأ.
- لا تحط كرت فوق وجه. اطلع صور `--stills` وشيك.
- 3 كروت كحد أقصى بنفس الوقت، وفرق 0.25–0.35ث بين دخول كل واحد.
- قبل التسليم: افحص بالصور إن العمود ما يغطي وجه/لابتوب، وحرّك `stack.x/y` بدل ما تفك الكروت عن بعض.
