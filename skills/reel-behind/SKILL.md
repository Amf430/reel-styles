# reel-behind — النص ورا الموضوع

مو ستايل لحاله: **خاصية تنضاف لأي جوب** (`"behind"`). الطبقة كاملة تنخفي مكان ما الموضوع (شخص/مبنى) قدّامها.

**اقرأ `reel-engine` أول.**

## الخطوات
1. **افصل الموضوع** على نفس مدة الجوب:
   - تصوير عادي — اختر الدرجة حسب اللقطة (لا تستخدم best لشي بسيط):
     ```bash
     python3 "$REEL/engine/segment.py" ../clip.mp4 --out reel_work/keyed/subject.mov --start 3 --end 9 --quality balanced
     ```
     | الدرجة | متى | السرعة (M4 Max) |
     |---|---|---|
     | `fast` | أشخاص بس، الحواف مو مهمة، نص كبير بعيد عن الحواف | أسرع شي |
     | `balanced` | الافتراضي: أشخاص، مباني، أثاث | ~0.3ث/فريم |
     | `best` | شعر، شماغ يطير، درابزين، حواف دقيقة قريبة من النص | ~1–3ث/فريم |
     لقطة بطيئة الحركة: `--every 2` يقسم الوقت نصين. وميض في الحواف: `--smooth 0.5`.
   - كروما: `key.py` (نفس المخرجات).
   - افتح `_qc.jpg` (الماجنتا = اللي انشال). الموضوع لازم يكون كامل؛ اللي ناقص منه بيطلع النص فوقه.
2. **أضف للجوب:**
   ```json
   { "style": "reel-hook", "start": 3, "end": 9, "behind": { "layer": "keyed/subject.mov", "feather": 1 },
     "params": { "lines": [ { "text": "*الرياض*", "size": 330 } ], "y": 0.5 } }
   ```
   `feather` = نعومة حافة القص (px).
3. `--stills` ← المحرّر (يعرض نفس القص) ← الرندر. الطبقة الناتجة شفافة وفيها القص جاهز — تنحط فوق الفيديو عادي.

## نصائح
- النص لازم يكون **أكبر من الموضوع وجزء منه يطلع حوله** وإلا ما يبان التأثير: كلمة وحدة ضخمة (250–400u) وراء الرأس/الكتف، أو اسم المشروع ورا المبنى في لقطة درون.
- ثيمات بدون حد (`clean`, `seen`) أحلى هنا؛ الحد الأسود يبرز القص.
- نطاق الفصل لازم يغطي مدة ظهور النص كاملة.

## حدود
- الفصل مو مثالي على الحواف المعقدة بـ fast/balanced — جرب best للقطات القريبة.
- glass + behind مع بعض ما يشتغلون (الاثنين يستخدمون قناة الفريمات).
