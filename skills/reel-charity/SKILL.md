# reel-charity: ستايل عاصم

**مأخوذ من:** فيديو جمعية عاصم لتأهيل وتدريب الأيتام (أكتوبر 2026). الفيديو الأصلي كان موشن After Effects، وانضافت له مقدمة وختام بهالستايل. علاء اعتمده، وطلبوا نفس بطاقة النهاية في فيديو رحماء.

**المحرّك:** HyperFrames (HTML + GSAP)، مو `reel-engine`. المخرج مقاطع شاشة كاملة، تنحط قبل الفيديو الأساسي وبعده.

## متى
- جمعية أو جهة عندها فيديو جاهز وتبغى مقدمة فيها شعارها الجديد، وختام فيه أرقامها وطرق التبرع.
- أي شعار يبغى له بناء مميز. علاء قال إن الـ fade «عادية».

## المخرج
| المقطع | المدة | المحتوى |
|---|---|---|
| `intro/` | 4.5 ث | حلقات تنغلق ← الشعار يتبنى ← نبضات ← دفع للأمام ويختفي في الأبيض |
| `end/` | 20.5 ث | أقراص ألوان تفتح المشهد ← الإحصائيات (0–8.6) ← الأقراص مرة ثانية ← الشعار يتبنى ← جملة الختام ← الأعمدة ← الشريط (8.6–20.5) |

1920×1080 بـ 30fps. لو تبغى 4K: `--resolution landscape-4k`.

## الخطوات
```bash
SK="$(cd ~/.claude/skills/reel-charity && pwd -P)"
bash "$SK/new.sh" ~/Desktop/<المشروع>/charity <الشعار.png> [focus-x,focus-y]
python3 "$SK/tools/qr.py" make https://<المتجر> --out ~/Desktop/<المشروع>/charity/assets/qr.svg
```
1. **الشعار:** `split_logo.py` يقسم الشعار لقطع: كل شكل متصل قطعة، والأشكال اللي بينها أقل من `--merge` بكسل تبقى قطعة وحدة.
   - يكتب `logo/parts.js`، وكل قطعة في سطر: `kind` و`at` و`dur`. **هذا الملف هو الإخراج.** عدّله لين يصير البناء منطقي: الرمز أول، بعده الكلمة، بعدها النقاط.
   - `focus` هي النقطة اللي تنزل عليها الحلقات. حطها على قلب الرمز، مو على الكلمة.
   - لو الشعار PDF أو AI، صدّره PNG شفاف بعرض 2000px أو أكثر.
2. **المحتوى:** كل النصوص في `content.js`: الألوان، والإحصائيات (من 2 لـ 4)، وجملة الختام، والأعمدة (2 أو 3: `qr` / `phone` / `bank`)، والشريط.
   - لو فيه أكثر من حساب بنكي، كل حساب يطلع في سطر. ولو حساب واحد، الآيبان ينكتب حرف حرف.
   - شعارات البنوك تنحط في `assets/` بالمشروع (`logo: "assets/alrajhi.svg"`).
3. **فحص بالصور:**
   ```bash
   cd ~/Desktop/<المشروع>/charity
   npx hyperframes snapshot intro --at 0.5,1.2,2.5,4 -o out/snap-intro
   npx hyperframes snapshot end --at 3.5,9.6,13.5,19 -o out/snap-end
   ```
4. **الرندر:**
   ```bash
   npx hyperframes render intro -o out/intro.mp4 --quality delivery
   npx hyperframes render end -o out/end.mp4 --quality delivery
   python3 "$SK/tools/qr.py" check out/end.mp4 --at 18 --expect https://<المتجر>
   ```
   لو `reelcore` مثبت، يشتغل بنفس الأوامر مكان `npx hyperframes`.
5. **التجميع:** مقدمة ← الفيديو الأصلي ← الختام. ثلاث أشياء لازم تنتبه لها:
   - **التعليق الأصلي:** أخّره بطول المقدمة (`adelay`) عشان يبقى متزامن.
   - **المؤثرات:** من `reel-sfx`. whoosh على الحلقات، وpop على القطع، وعدّاد مع الأرقام.
   - **المعاينة:** لازم تكون أقل من 30MB عشان توصل بالجوال.

## أنواع الحركة (`kind` في parts.js)
| النوع | الحركة | يناسب |
|---|---|---|
| `rtl` / `ltr` | مسح أفقي | كلمات، خطوط عريضة |
| `ttb` / `btt` | مسح عمودي | ألف، أعمدة، خطوط طويلة |
| `cx` / `cy` | ينفتح من خط النص | إطار، فاصل، خط أرضي |
| `pop` | يكبر بارتداد | رأس، دائرة، رمز صغير |
| `rain` | ينزل ويرتد | نقاط، تشكيل، علامات صغيرة |
| `slide` | ينزلق من ورا الرمز ببلور | الكلمة جنب الرمز |

كل قطعة تدخل كطبقات: لونين accent تحت، والقطعة الأصلية فوقهم، وبعدها الـ accents تختفي.

## قواعد اتعلمناها (عاصم)
- أسطر التواصل تكون فوق بعض بنفس الطول، والأيقونات في عمود واحد. طلب علاء: «كل السطور نفس الطول».
- الـ QR لازم ينقرأ من فريم الفيديو نفسه (`qr.py check`). ولو فيه غلط في الدومين أو الآيبان، **بلّغ عنه وما تصلحه بصمت**.
- الأرقام والآيبان والروابط تجي من الجمعية بس، لا تألف شي.
- بيانات العميل (الشعار، الآيبان، الـ QR) تبقى في مجلد المشروع. **لا تدخلها في ريبو reel-styles**، الريبو عام.

## معتمد ✅
- بناء الشعار بطبقات ملونة + حلقات تنغلق على قلب الرمز (عاصم، رحماء).
- عدّاد بدائرة تمتلي، والرقم يكبر مع قيمته ويرتد.
- بطاقة نهاية بثلاث أعمدة + شريط سفلي (عاصم، ونفسها في رحماء).
