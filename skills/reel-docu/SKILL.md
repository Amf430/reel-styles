# reel-docu — وثائقي أحمر

ستايل القصص والوثائقيات: كرة حمرا لامعة (تدرج غامق + لمعة + حد فاتح)، كشيدة تنضم وقت الظهور، ومربعات نص بنفس اللون. الكود كله هنا؛ المرجع كان معاينة شكلية فقط.

**اقرأ `reel-engine` أول.**

## الحقول (params)
```json
{ "items": [
  { "type": "count", "value": "24", "sub": "عاماً", "in": 1.0, "out": 4.0, "x": 0.22, "y": 0.12, "size": 110 },
  { "type": "circle", "text": "القصة | الكاملة", "in": 4.2, "out": 7.0, "x": 0.7, "y": 0.3 },
  { "type": "box", "text": "وهل تكون هذه البداية | لمرحلة جديدة بالكامل؟", "in": 7.2, "out": 10, "y": 0.7 },
  { "type": "title", "text": "خلف | الكواليس", "in": 10.2, "out": 13, "y": 0.5 },
  { "type": "sweep", "in": 13.0, "out": 13.7 }
] }
```
| type | الشكل | حقول |
|---|---|---|
| `count` | كرة تنزل من فوق وترتد، رقم يعدّ + كلمة تحته بكشيدة تنضم | `value`, `sub`, `kashida` |
| `circle` | كرة تكبر وفيها سطرين (`\|`) ينكشفون بكشيدة تنضم | `text`, `kashida` |
| `box` | مربع أحمر ينفتح بنص، وبعد ثانية يصير شفاف ويبقى النص | `text`, `keep` (شفافية المربع الباقية، 0.25) |
| `title` | عنوان أبيض كبير ينكشف ورا كرة ضوء حمرا تمشي | `text`, `kashida`, `keep` |
| `sweep` | وميض ضوء أحمر يعبر الشاشة (بين لقطتين) | `dur`, `width` |
- لكل item: `in`, `out`, `x`, `y` (المركز)، `size` (u، 110)، `accent`, `font`, `sfx`, `xf`.

## الثيمات
`red` (الأصلي) · `black` · `gold` · `blue` · `seen` (عنابي).

## نصائح
- `count` في زاوية فوق بعيد عن الوجه. `sweep` على القطع بالضبط (ابدأه قبل القطع بـ 0.3ث).
- الكشيدة تحتاج كلمات فيها حروف تقبل التمطيط.
