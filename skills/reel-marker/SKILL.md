# reel-marker — ملاحظات بخط اليد

ترند 2026: «hand-written or marker-style annotation layers». ممتاز للعقار: دائرة حول ميزة، سهم للشباك، خط تحت السعر.

**اقرأ `reel-engine` أول.**

## الحقول (params)
```json
{ "marks": [
  { "type": "circle", "x": 0.6, "y": 0.6, "w": 0.13, "h": 0.42, "in": 25.0, "out": 30.5, "label": { "text": "غرفة ماستر", "x": 0.6, "y": 0.28 } },
  { "type": "arrow", "x1": 0.25, "y1": 0.85, "x2": 0.38, "y2": 0.6, "bend": 0.3, "in": 25.6, "out": 30.5, "label": { "text": "شبابيك كبيرة", "x": 0.2, "y": 0.92 } },
  { "type": "underline", "x": 0.72, "y": 0.2, "w": 0.18, "double": true, "in": 26.2, "out": 30.5 },
  { "type": "check", "x": 0.86, "y": 0.75, "w": 0.06, "in": 26.6, "out": 30.5 }
] }
```
| النوع | المكان | خيارات |
|---|---|---|
| `circle` | مركز `x,y`، قطر `w` (و`h` اختياري) | — |
| `box` | زاوية `x,y` + `w,h` | — |
| `underline` | بداية `x,y` + `w` | `double`, `wave` |
| `arrow` | من `x1,y1` إلى `x2,y2` | `bend` (−/+ اتجاه الانحناء)، `head` |
| `check` / `cross` | مركز `x,y`، حجم `w` | — |
| `highlight` | `x,y,w,h` — مسحة هايلايتر (استخدم ثيم `highlighter`) | — |
| `burst` | مركز + `w` — خطوط حوالين شي (لفت انتباه) | `count` |
| `scribble` | `x,y,w,h` — شخبطة/شطب | — |
- لكل علامة: `in`, `out`, `draw` (مدة الرسم)، `color`, `width`, `seed` (شكل يد مختلف)، `roughness`.
- `label`: نص أو `{ text, x, y, size, rot, color, font }` — يطلع بعد ما تخلص الرسمة. الخط الافتراضي Aref Ruqaa (Google Fonts — يحتاج نت وقت الرندر).
- الضربات متعددة (السهم، البوكس، الخطأ) تنرسم بالترتيب.
- عام: `draw`, `roughness` (0 = نظيف، 2 = يد مستعجلة)، `double` (الضربة مرتين).

## الثيمات
`red` (الكلاسيكي) · `yellow` · `white` · `pen` (أسود رفيع — على خلفيات فاتحة) · `seen` (بيج) · `highlighter`.

## نصائح
- علامة أو علامتين بنفس الوقت؛ كل وحدة تدخل بعد الثانية بـ 0.4–0.6ث مع الكلام.
- في المحرّر: اضغط العلامة وحرّكها/كبّرها على الشي المطلوب بدل ما تحسب الأرقام.
- لقطة تتحرك؟ العلامات ثابتة — خلها على لقطات ثابتة أو قصيرة.
