# reel-transitions — انتقالات وحركة كاميرا

الانتقال متمركز على **القطع**: قبل القطع يبني على اللقطة الأولى، القطع يصير في ذروته، وبعده يهدى على اللقطة الثانية — نفس طريقة انتقالات المونتيرين، وكل فريم يحتاج فريمه بس.

**اقرأ `reel-engine` أول.**

## المخرج
ProRes 422HQ (مو شفاف) لنطاق الجوب: **يحل محل الكليب** في البريمير لنفس الفترة (حطه فوقه بنفس الوقت). معه `<name>_sfx.wav`.

## الحقول (params)
```json
{ "cuts": [
    { "t": 3.233, "fx": "zoom", "dur": 0.6 },
    { "t": 7.333, "fx": "iris", "dur": 1.0, "color": "#ff7a1a" }
  ],
  "camera": [
    { "type": "zoom", "in": 0, "out": 3.2, "from": 1, "to": 1.2 },
    { "type": "punch", "in": 4.0, "out": 5.5, "scale": 1.25 },
    { "type": "shake", "in": 5.5, "out": 7, "amount": 1 }
  ] }
```
- أوقات القطع: `ffmpeg -i clip.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep -o "pts_time:[0-9.]*"`.
- الجوب `start/end` يغطي كل الانتقالات وحركات الكاميرا (مثلاً 0.5ث قبل أول قطع).
- لكل cut: `t` (وقت القطع)، `fx`، `dur` (0.5) أو `from/to`، `sfx` (false أو id بديل)، وخيارات الـ fx.

| fx | الشكل | خيارات |
|---|---|---|
| `whip` | سحبة أفقية بموشن بلور | `dir: "left"` |
| `zoom` | زووم داخل بموشن بلور شعاعي | — |
| `spin` | دوران مع زووم وبلور | — |
| `defocus` | فوكس سينمائي: بلور + بوكيه ضوء | — |
| `pixel` | بكسلات تكبر لين بلوك LED ثم ترجع | — |
| `grid` | الصورة تتقسم مربعات تصغر وترجع | `cols`, `color` |
| `iris` | حلقة نار تقفل على المركز وتنفتح على اللقطة الجاية | `color` |
| `glass` | لوح زجاج يعبر الشاشة والقطع وراه | — |
| `xray` | نيجاتيف + أشعة ضوء على القطع | — |
| `streak` | زووم + خط ضوء أفقي | `color`, `y` |
| `flash` | ومضة (أبيض أو أي لون) | `color`, `strength` |
| `glitch` | قلتش: شرائح منزاحة وخطوط ألوان | — |

حركة الكاميرا (`camera`): `punch` (قفزة زووم سريعة وتثبت: `scale`, `dur`, `x`, `y`) · `zoom` (Ken Burns: `from`, `to`, `x0/x1/y0/y1`) · `pan` (`scale`, `x0`, `x1`) · `shake` (`amount`, `freq`).

## الصوت
whip/grid → whip، zoom/streak → سحب للداخل **ينتهي على القطع**، iris → سحبة عكسية تنتهي على القطع، flash/xray → ضربة على القطع، defocus → هواء عميق، pixel/glitch → قلتش، punch → ضربة خفيفة.

## نصائح
- انتقال واحد قوي أحسن من عشرة. خلّ `dur` 0.4–0.7 للسوشل.
- `iris`/`glass`/`xray` لحظات كبيرة؛ `whip`/`zoom` للإيقاع السريع.
