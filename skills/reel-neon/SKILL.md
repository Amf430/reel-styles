# reel-neon — عنوان نيون

مأخوذ من ريلز «كل مدرسة ناجحة» (AE: Deep Glow، Radius قليل، Exposure ~0.3). يطلع أحلى على خلفية غامقة (studio3d/backdrop أو تصوير ليلي)؛ على مشهد فاتح التوهج يضعف — قل للمستخدم.

**اقرأ `reel-engine` أول.**

## الحقول (params)
```json
{
  "lines": [ { "text": "كل مدرسة", "size": 120, "weight": 800 }, { "text": "نـاجـحـة", "size": 150, "weight": 900 } ],
  "x": 0.5, "y": 0.18, "align": "center", "line_gap": 0.12, "max_width": 0.86,
  "in": 2.0, "out": 7.5, "anim": "rise", "anim_dur": 0.9, "out_dur": 0.4, "stagger": 0.18,
  "outline": false,
  "glow": { "intensity": 1, "spread": 1, "bloom": 0.55, "hum": 0.03 }
}
```
- `x,y` مركز الكتلة (أو حافتها مع `align: right|left`). `size` بوحدة u (px على 1080). السطر الأعرض من `max_width` يصغر تلقائياً.
- لكل سطر: `glow`, `core` (ألوان تتخطى الثيم)، `font` (مع `google_fonts`)، `in`.
- `anim`: `rise` (يطلع من تحت ببلور) · `flicker` (تشغيل نيون: تقطيع ثم ثبات — حتمي) · `write` (ينكشف بالاتجاه) · `glow` (التوهج يزيد تدريجياً).
- `outline: true` = شكل أنبوب نيون (حد بدون تعبئة).
- الكشيدة في Tajawal قصيرة: «نـاجـحـة» ⇒ للتمطيط الواضح «نــاجــحــة».

## الثيمات
`amber` (برتقالي ذهبي — مثل الريلز الأصلي) · `seen` (`#ffe066` نفس v6) · `pink` · `ice` · `lime` · `white`.

## ملاحظة لسين
seen-motion (v6) **رفض** الفوشي/البرتقالي والوميض المتكرر لفيديوهات سين الإعلانية. لشغل سين الرسمي: ثيم `seen` و`anim: rise` أو `glow` — لا `flicker`. للسوشل ميديا الحرية أوسع.
