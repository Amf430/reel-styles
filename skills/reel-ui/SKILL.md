# reel-ui — عناصر واجهة التطبيقات

ترند 2026: «UI-style overlays, minimal animated icons, progress bars». المشاهد يعرف شكلها فوراً فتوصل الرسالة بسرعة.

**اقرأ `reel-engine` أول.**

## الحقول (params)
كل عنصر: `type`, `x,y` (مركزه، نسب)، `w` (عرض، نسبة)، `size` (حجم الخط بوحدة u، افتراضي 34)، `in`, `out`.
| type | حقول | الحركة |
|---|---|---|
| `notification` | `title`, `text`, `time` ("الآن")، `icon` (صورة) أو `app_letter`, `app_color` | ينزل من فوق بارتداد |
| `chat` | `messages: [{text, me}]`, `gap` (ث بين الرسائل) | الرسائل وحدة وحدة، «يكتب…» قبل رد الطرف الثاني. `me` يطلع على اليسار في العربي (مثل واتساب) |
| `search` | `text`, `speed` (حرف/ث) | يكتب حرف حرف مع مؤشر |
| `button` | `text`, `done_text`, `tap` (وقت الضغطة)، `color` | مؤشر يدخل ويضغط، الزر يتحول لحالة «تم» |
| `progress` | `from`, `to` (افتراضي مدة العنصر)، `color` | يتعبى مع الوقت (للريل كامل: من 0 لآخره) |
| `badge` | `text`, `color`, `text_color` | ينط بدوران خفيف |
| `checklist` | `items: []`, `gap` | صح ✓ وحدة وحدة |
| `rating` | `value` (1–5) | النجوم تتعبى بالتتابع |
- `notification`, `search`, `checklist` بخامة زجاج iOS (تبلّر الفيديو اللي وراها — `material_blur`).
- كل عنصر قطعة في المحرّر: انقله/كبّره/وقّته من هناك.

## الثيمات
`ios-light` · `ios-dark` · `whatsapp` · `seen`.

## نصائح
- لا تحط أكثر من 2–3 عناصر بنفس اللحظة — المثال فيه الكل للعرض بس.
- الإشعار: أول 1–2 ثانية كـ hook («شقة متاحة الآن…»).
- المحادثة: سؤال العميل + الرد بالسعر/الميزة = قصة سريعة.
- الأيموجي يطلع بخط النظام وقت الرندر (Apple Color Emoji على الماك).
