# reel-engine — المحرّك المشترك

كل ستايل `reel-*` هو مجلد فيه `scene.html` (المشهد) و`presets.json` (القيم الافتراضية والثيمات والسلايدرات) و`SKILL.md` (متى يُستخدم وقائمة المعتمد/المرفوض). المحرّك واحد للكل.

```bash
REEL="$(cd ~/.claude/skills/reel-engine && pwd -P)/../.."   # جذر الريبو (المهارات روابط رمزية له)
```

## المتطلبات (تحقق مرة لكل جهاز)
- `python3` + `playwright` (`pip3 install playwright`)، وChromium من Playwright. المحرّك يلقى أي نسخة Chromium موجودة حتى لو رقمها مختلف عن الباكج (أو حدد `REEL_CHROMIUM=/path`).
- `ffmpeg` فيه `prores_ks` (نسخة Homebrew فيها).
- `bash "$REEL/install.sh"` يربط المهارات في `~/.claude/skills/` ويفحص كل هذا.

## المشروع والجوبات — فيديو واحد = مشروع واحد
كل محادثة فيها فيديو واحد. اعمل جنبه مجلد `reel_work/` (لا تعدّل ولا تحذف ملفات المستخدم) وفيه:
```
reel_work/
  project.json        { "video": "../clip.mp4", "jobs": ["cards.json", "title.json"] }
  cards.json          جوب لكل شغلة (ستايل واحد)
  title.json
  keyed/              مخرجات key.py (لو فيه كروما)
  out/                الطبقات والبرفيو
```
جوب (التعليقات `//` للشرح فقط — JSON الحقيقي بدونها):
```json
{
  "style": "reel-glass",
  "name": "cards",                  // اسم الطبقة الناتجة
  "start": 12.0, "end": 18.5,       // نطاق الرندر على تايملاين الفيديو (المحرّر يوسّعه تلقائياً)
  "theme": "frost",
  "params": { ... }                 // فوق الافتراضيات؛ كل ستايل يشرح حقوله في SKILL.md حقه
}
```
- الجوب داخل مجلد فيه project.json ياخذ الفيديو من المشروع (أو حط `"video"` فيه).
- كل المقاسات بوحدة `u` = 1px على ضلع قصير 1080، والمواقع نسب من الإطار (0..1) ⇒ نفس الجوب يطلع صح طولي وعرضي. 4K يترندر بـ device scale 2 تلقائياً.
- كل قطعة متحركة (كرت، عنوان، عنصر ديكور) لها `xf`: `{ "x": 0.05, "y": -0.02, "rot": 6, "scale": 1.1, "opacity": 0.9 }` (x/y إزاحة كنسبة من الإطار). المحرّر يكتبها؛ تقدر تكتبها يدوي.

## الأوامر
```bash
python3 "$REEL/engine/player.py"  reel_work/project.json [--t 13]   # المحرّر — افتحه للمستخدم
python3 "$REEL/engine/render.py"  reel_work/project.json --job cards --stills 13.2,15.8   # صور للفحص
python3 "$REEL/engine/render.py"  reel_work/project.json           # كل الجوبات + برفيو للفيديو كامل
python3 "$REEL/engine/render.py"  reel_work/project.json --job cards [--workers 6] [--mblur 4]
python3 "$REEL/engine/transcribe.py" clip.mp4 --out reel_work/words.json   # توقيت كل كلمة (Whisper محلي) أو --srt
python3 "$REEL/engine/key.py"     clip.mp4 --out reel_work/keyed/subject.mov --start 12 --end 18.5
python3 "$REEL/engine/shadow.py"  subject.mov --out shadow.mov     # (render.py يسويه تلقائياً)
python3 "$REEL/engine/composite.py" --out p.mp4 --size 1080,1920 --dur 6 a.mov b.mov@0.1,0,0.8,1
```

### المحرّر (player.py)
الفيديو كامل وكل الجوبات فوقه — نفس الفريمات بالضبط مثل الرندر. شغّله وافتح الرابط في Browser pane (`preview_start` بالرابط) أو قل للمستخدم يفتحه.
- **تايملاين:** صور مصغرة + موجة الصوت + خطوط القطع. كل قطعة بلوك: سحب = تقديم/تأخير، الأطراف = الدخول/الخروج. يلتصق بالفريمات ورأس التشغيل والقطع والقطع الثانية (`shift` = حر). بلوك «render range» لكل جوب. `ctrl`+عجلة = زوم.
- **Transform على الفيديو:** اضغط القطعة واسحبها = position · المقبض فوق = rotation · الزاوية = scale · `shift` تقييد/15° · دبل كلك = reset. اللوحة اليمين: أرقام دقيقة + opacity + in/out + سلايدرات الستايل.
- **مفاتيح:** `space` · `←/→` ثانية (`shift` 5) · `,` `.` فريم · `i`/`o` دخول/خروج القطعة عند رأس التشغيل · `alt+←/→` تحريك القطعة فريم (`shift` 10) · `b` قبل/بعد · `w` wipe · `h` إخفاء اللوحات · `⌘Z`/`⌘⇧Z` · `⌘S` حفظ.
- **الحفظ** يكتب في ملفات الجوب تعديلات المستخدم بس (مو الافتراضيات)، ويوسّع نطاق الرندر ليغطي كل القطع. بعد الحفظ اقرأ الملفات وكمّل منها — لا تكتب فوق تعديلاته.
- ظل المقدّم في reel-backdrop ما يظهر في المحرّر (يتسوى وقت الرندر).

## المخرجات (out/<style>/)
| الملف | وش هو | وين يروح |
|---|---|---|
| `<name>_<0m12s00>.mov` | الطبقة: ProRes 4444 شفاف (glass/neon) أو ProRes 422HQ (خلفيات) | البريمير، عند الوقت المكتوب في الاسم |
| `…_subject.mov` | المقدّم مفصول ومحطوط بمكانه (full frame شفاف) | فوق الخلفية |
| `…_shadow.mov` | ظل المقدّم (backdrop فقط؛ في studio3d الظل داخل الخلفية) | بين الخلفية والمقدّم |
| `…_preview.mp4` | كل شي مركّب مع الصوت | للمراجعة والإرسال فقط |
| `….meta.json` | التوقيت والمقاس ومكان المقدّم | مرجع |
| `out/project_preview.mp4` | الفيديو كامل وكل الطبقات عليه مع الصوت | المراجعة/الإرسال |

ترتيب الطبقات في البريمير (من تحت): الخلفية → الظل → المقدّم → neon/glass.

## فصل المقدّم (key.py)
- يشتغل فقط إذا الخلفية تنفصل: كروما خضراء/زرقاء، أو استوديو بخلفية سادة وكاميرا ثابتة (`--mode plate --plate empty.png` = فريم للمكان فاضي).
- **تصوير في موقع حقيقي = لا تفصل.** استخدم الستايلات اللي فوق الفيديو (glass, neon) بس.
- المفتاح difference key (`G − max(R,B)`): الثوب الأبيض والرمادي والبشرة تبقى صلبة. لو بقى أخضر: `--similarity 0.1`. لو الأطراف تنأكل: `--similarity -0.05`. حوامل/إضاءات على الأطراف: `--matte x,y,w,h`.
- دايماً افتح `_qc.jpg` (الماجنتا = اللي انشال) قبل ما تكمل، وشغّله على نفس `--start/--end` حق الجوب.

## سير العمل الإلزامي
1. افهم الطلب → اختر الستايل → `reel_work/project.json` + جوب لكل شغلة.
2. `--stills` على 2–3 لحظات مهمة → شوف الصور بنفسك → صحح (تناسق، ما يغطي وجه).
3. افتح المحرّر للمستخدم يضبط التوقيت والمواضع بنفسه. المستخدم يحب تجربة 5–10 ثواني قبل التعميم.
4. بعد ما يحفظ: الرندر الكامل → ارسل `project_preview.mp4` واذكر أسماء الطبقات ووقت كل وحدة.
5. ملاحظة اعتمدها أو رفضها المستخدم؟ اكتبها في قسم «معتمد/مرفوض» في SKILL.md حق الستايل (شوف «تحديث الستايلات»).

## تحديث الستايلات (الريبو `Amf430/reel-styles`)
الستايلات تتطور مع كل شغل. أي تعديل على ستايل أو المحرّك:
1. الريبو هو مصدر المهارات (المجلدات في `~/.claude/skills/reel-*` روابط له): `cd "$REEL"`.
2. فرع جديد من `dev`: `git switch dev && git pull && git switch -c style/<name>-<change>`.
3. عدّل `scene.html` / `presets.json` / `SKILL.md` (المعتمد/المرفوض + سطر في «سجل التغييرات»).
4. اختبر بـ `--stills` على فيديو حقيقي.
5. commit باسم المستخدم فقط (بدون أي ذكر لـ AI)، `git push -u origin HEAD`، و`gh pr create --base dev`.
6. لا push مباشر على `dev` أو `main` أبداً. الترقية dev→main فقط لما يقول المستخدم «ارفع».
- قيمة جديدة بس (ثيم/لون معتمد)؟ أضفها كـ theme في presets.json بدل ما تغيّر الافتراضي.

## أدوات الـ AI
transcribe.py (وأدوات الفصل الجاية) تشتغل في بيئة Python 3.11 خاصة: `~/.reel-styles/venv` والنماذج في `~/.reel-styles/models` — برا الريبو، تنعمل تلقائياً أول استخدام (تحتاج نت مرة وحدة). لا تثبّت شي في Python النظام.

## مشاكل معروفة
- `scene failed to load` → شوف رسائل الكونسول في الخطأ؛ جرّب `player.py` وافتح الكونسول.
- خطوط Google: `"params": {"google_fonts": ["Cairo"]}` ثم `"font": "Cairo"` في السطر (تحتاج نت وقت الرندر). Tajawal مضمّن.
- الكشيدة (ـ) في Tajawal قصيرة؛ للتمطيط الواضح كرر 2–3 مرات.
