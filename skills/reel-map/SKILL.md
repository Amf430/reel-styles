# reel-map — خريطة الموقع

ترند 2026 (documentary hybrid): خرائط وخطوط زمنية تخلي المعلومة تثبت. للعقار: «وين المشروع وكم يبعد عن…».

**اقرأ `reel-engine` أول.**

## الحقول (params)
```json
{
  "center": "حي النرجس، الرياض",
  "camera": { "zoom_from": 10.5, "zoom_to": 14, "dur": 3 },
  "pin": { "label": "مشروع سين — النرجس", "sub": "شقق 3 غرف", "at": 2.4 },
  "route": { "points": [ [24.7743, 46.7386] ], "start": 0.6, "dur": 2.0 },
  "pois": [ { "label": "طريق الملك سلمان", "sub": "3 دقائق", "at": [24.8365, 46.6620] } ],
  "frame": "full"
}
```
- **المكان** (`center`, نقاط `route.points`, `pois[].at`): `[lat, lon]` أو رابط قوقل ماب (اللي فيه `@lat,lon`) أو اسم («النرجس الرياض»). الأسماء تنبحث في Nominatim — تأكد من الدبوس في الصور، ولو غلط أعط إحداثيات (الأدق دايماً: رابط قوقل ماب من العميل).
- `camera`: يقرّب من `zoom_from` لـ `zoom_to` (مستويات OSM: 10 مدينة، 13 حي، 15 شوارع، 17 مباني) خلال `dur` من `start`.
- `pin.at` وقت نزول الدبوس، `label`/`sub` الكرت فوقه.
- `route`: نقاط البداية (والمرور) → ينتهي عند المشروع، يترسم خلال `dur`.
- `pois`: معالم بالمسافة/الوقت — `sub` تكتبه أنت (ما نحسب أوقات قيادة).
- `frame`: `full` (الخريطة تغطي الشاشة — لقطة قطع) أو `card` + `card.{x,y,w,h,radius}` (كرت فوق الفيديو).

## التجهيز (تلقائي)
قبل الرندر/المحرّر، `maptiles.py` يحدد الأماكن ويحمّل البلاطات اللي تحتاجها الكاميرا مرة وحدة (كاش في `~/.reel-styles/tiles`، تحتاج نت أول مرة؛ مدى زوم كبير = بلاطات أكثر = أبطأ). حسب سياسة OSM: User-Agent معرّف، كاش، بدون تحميل بالجملة. **مكتوب «© OpenStreetMap» في الزاوية دايماً — لا تشيله** (شرط الرخصة).

## الثيمات
`night` (كحلي + برتقالي) · `day` (فاتح + أحمر) · `seen` (عنابي + بيج) · `teal`.

## حدود
- البلاطات صور (مو فيكتور): أسماء الشوارع من OSM تطلع بلغة الخريطة، وما تنعدّل.
- الكاميرا تقرّب على المركز بس (بدون ميلان 3D حالياً).
