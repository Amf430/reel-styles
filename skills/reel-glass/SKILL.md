# reel-glass — كروت زجاجية

مأخوذ من تحليل ريلز «Glass Shape» (After Effects: Brightness −50 + Gaussian Blur + Stroke Soft Light 70%، حركة Position سريعة ثم بطيئة). هنا نفس الوصفة بالكود.

**اقرأ `reel-engine` أول** (الجوب، الأوامر، التسليم، تحديث الستايل).

## متى
- مميزات عقار (غرف، مساحة، موقع)، أرقام (+250,000 م²)، عناوين صغيرة، خطوات.
- أي تصوير — ما يحتاج فصل المقدّم.

## المخرج
ProRes 4444 شفاف: برا الكرت شفاف، وداخل الكرت **البلور محسوب من الفيديو نفسه** ⇒ حطه فوق نفس الكليب وعلى نفس الوقت بالضبط (اسم الملف فيه الوقت). لو تحرك الكليب في البريمير، أعد الرندر.

## الحقول (params)
```json
{
  "cards": [
    { "kind": "card", "text": "٣ غرف نوم", "sub": "ماستر بدورة مياه خاصة", "icon": "bed",
      "x": 0.62, "y": 0.47, "w": null, "in": 24.7, "out": 30.6, "from": "bottom" },
    { "kind": "stat", "value": "+180", "unit": "م²", "label": "مساحة الشقة", "icon": "area", "x": 0.62, "y": 0.18, "in": 24.4, "out": 30.6 },
    { "kind": "pill", "text": "جاهزة للسكن", "icon": "check", "x": 0.62, "y": 0.72, "in": 25.0, "out": 30.6 }
  ]
}
```
- `x,y` = الزاوية العلوية اليسرى للكرت كنسبة من الإطار. `w` نسبة من العرض (فاضي = حسب المحتوى). `h` اختياري.
- `kind`: `card` (عنوان + سطر فرعي) · `stat` (رقم يعدّ من صفر خلال `count_dur` ثانية، يحافظ على +/الفواصل/الأرقام العربية) · `pill` (كبسولة سطر واحد).
- `in/out` بالثواني على تايملاين الفيديو. `from`: bottom/top/left/right. لكل كرت: `in_dur`, `out_dur`, `dist`, `size`, `sub_size`, `radius`, `tint`, `align: "center"`.
- الأيقونات: bed, bath, area, pin, tag, check, star, phone, building, key, car, clock, arrow, sparkle, home, chart (`engine/web/icons.js` — أضف جديد هناك).
- عام: `glass.{blur, brightness, saturate, radius, stroke, stroke_opacity, highlight, shadow}`, `text.{size, weight, sub_size, icon_size}`, `motion.{in, out, dist, content_delay}`, `dir` (rtl).

## الثيمات
`frost` (أبيض فاتح — للمشاهد الفاتحة) · `smoke` (زجاج غامق — للمشاهد الغامقة/الليل، أقرب لريلز AE الأصلي) · `seen` (عنابي + بيج) · `warm` · `ice`.

## نصائح
- المشهد فاتح جداً؟ `smoke` أو `glass.brightness` 0.5–0.6 عشان النص الأبيض يقرأ.
- لا تحط كرت فوق وجه. اطلع صور `--stills` وشيك.
- 3 كروت كحد أقصى بنفس الوقت، وفرق 0.25–0.35ث بين دخول كل واحد.
